CREATORHUB — PROJETO LIMPO PARA GERAR APK

Este ZIP contém um projeto Android completo com WebView e um painel CreatorHub local.
Não precisa de gradlew: o GitHub Actions instala Gradle 8.9 automaticamente.

COMO CRIAR O NOVO REPOSITÓRIO PELO CELULAR
1. Crie um repositório NOVO no GitHub.
2. Extraia este ZIP no celular.
3. Envie TODO o CONTEÚDO da pasta CreatorHub-NOVO para a raiz do repositório.
   Importante: envie a pasta .github também. Ela contém o workflow.
4. Faça commit na branch main.
5. Abra a aba Actions.
6. Selecione "Gerar APK do CreatorHub" e aguarde terminar.
7. Abra a execução concluída e baixe o artefato "CreatorHub-APK".

ESTRUTURA IMPORTANTE
- app/src/main/AndroidManifest.xml
- app/src/main/java/com/creatorhub/MainActivity.kt
- app/src/main/assets/index.html
- app/build.gradle
- .github/workflows/build-apk.yml

OBSERVAÇÕES
- O aplicativo abre o arquivo HTML local dentro de um WebView.
- Os dados ficam salvos localmente no aparelho, usando armazenamento do WebView.
- Este projeto foi montado como estrutura limpa; o APK ainda precisa ser compilado no GitHub Actions.
- Não misture estes arquivos com os arquivos antigos. Use um repositório novo e envie tudo desde a raiz.
